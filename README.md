# Сайт-тренажёр по русскому языку

Статический учебный сайт: тренажёры по фразеологизмам, ударениям и паронимам, а также урок по частям речи с теорией и упражнениями.

Сайт: https://wizzzfox.github.io/russian-trainer/

## Структура

- `index.html`, `home.js`: главная страница и прогресс урока.
- `frazeologizmy/index.html`: индивидуальные режимы и командная игра.
- `udareniya/index.html`: карточки, задание 4 ЕГЭ, словник и тенденции.
- `paronimy/index.html`: выбор паронима, поиск ошибки, задание 5 ЕГЭ и словник.
- `uroki/chasti-rechi/index.html`: последовательный список 12 блоков.
- `uroki/chasti-rechi/blok.html`: выбранный блок и его пункты.
- `uroki/chasti-rechi/tekst.html`: текстовая версия урока без JavaScript.
- `scripts/`, `tests/`, `output/lessons/`: локальные исходники, проверки, согласованная теория и рабочие материалы.

Ответы и прогресс урока сохраняются в браузере на устройстве ученика. Учётных записей и базы данных нет. Изменения ответов из разных вкладок объединяются; повторное прохождение сбрасывает только выбранный блок.

## Проверка

Для проверок нужен Node.js. Для браузерных проверок также нужны Playwright и запущенный локальный сайт на порту 8765. В Windows по умолчанию используется Edge; другой браузер можно указать через `PLAYWRIGHT_CHANNEL`.

```powershell
node scripts/check-site.cjs
node scripts/check-site.cjs --browser
```

Первая команда проверяет данные, оценивание, сохранения, источники и отбор заданий. Вторая дополнительно проходит все упражнения урока и режимы тренажёров в браузере, проверяет разные размеры экрана, восстановление прокрутки, несколько вкладок и письменные черновики.

Снимки для визуального осмотра сохраняются в `output/site-preview/`, `output/lesson-preview/` и `output/audit-20261019/`. Они не заменяют сами автоматические проверки.

## Сборка урока

```powershell
node scripts/build-lesson.cjs
```

Сборка использует согласованные тексты из `output/lessons/` и задания из `scripts/*-lesson.cjs`. Нужны пакеты `marked` и `lucide`; путь к ним можно передать в `CODEX_NODE_MODULES`. Готовый сайт работает без этих пакетов и без сервера приложения.

Номер обновления скриптов и стилей задаётся только в `scripts/lesson-assets.cjs`. Сборка синхронизирует его во всех страницах. Если изменился только код интерфейса, после обновления номера достаточно запустить:

```powershell
node scripts/lesson-assets.cjs
```

Версии учебного содержания и сохранённого прогресса не следует менять при правках оформления.

## Публикация

Репозиторий: `wizzzfox/russian-trainer`. GitHub Pages публикует ветку `main`, папку `/root`.

В опубликованную сборку входят `index.html`, `home.js`, `.nojekyll` и папки `frazeologizmy`, `udareniya`, `paronimy`, `uroki`. Пособия, рабочие тексты, снимки, локальные исходники сборки и служебные копии репозитория туда не переносятся. Изменения учебных файлов следует проверять до отправки.

Служебные папки `tmp`, `publish_bare`, `.publish-russian-trainer`, `.publish-russian-trainer-2` не являются частью сайта. Не следует загружать всю рабочую папку целиком.
